# Connorwyatt Tap

## How do I install these formulae?

`brew install connorwyatt/tap/<formula>`

Or `brew tap connorwyatt/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "connorwyatt/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
